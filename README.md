# 🔎 CaseNote 검색기 (케이스노트 검색기)

**어떤 웹페이지에서든 판례 번호와 법률 조문을 자동으로 인식하여, 클릭 한 번으로 CaseNote 팝업을 띄워주는 Chrome 확장 프로그램입니다.**

이 확장 프로그램은 CaseNote의 공식 애플리케이션이 아닌, 개인 개발자가 편의를 위해 제작한 서드파티(3rd-party) 도구입니다. CaseNote 서비스와 관련된 모든 권리는 원저작자에게 있습니다.

## ✨ 주요 기능

* **자동 하이라이트 검색**: 웹페이지를 읽는 중 판례 번호나 '법률 이름 + 조문' 형식의 텍스트를 발견하면 자동으로 하이라이트를 표시합니다. 하이라이트를 클릭하기만 하면 즉시 CaseNote 검색창이 나타납니다. (팝업 설정에서 ON/OFF 가능)
* **지능형 우클릭 검색**: `제21조`와 같이 법률 이름이 명시되지 않은 텍ext는, 직접 드래그 후 마우스 오른쪽 버튼을 클릭하여 원하는 법률을 지정해 검색할 수 있습니다.
* **맞춤형 법률 메뉴**: 팝업창의 '법률 관리' 기능을 통해, 내가 자주 사용하는 법률만 골라 우클릭 메뉴에 추가하고 즐겨찾기로 등록할 수 있습니다.
* **스마트 검색 로직**: 판례 번호의 종류(대법원/하급심)를 분석하여, 불필요한 확인 과정 없이 가장 빠른 방식으로 검색을 실행합니다.
* **최근 조회 기록**: 팝업창에서 최근에 검색했던 항목을 확인하고, 클릭 한 번으로 다시 열어볼 수 있습니다.

## 🚀 설치 방법

### 1. 웹 스토어를 통한 설치 (권장)

[![Chrome 웹 스토어에서 다운로드](https://storage.googleapis.com/web-dev-uploads/image/WlD8wC6g8khYWPJUsQceQkhXSlv1/iNEddTyWiMfLSwFD6qGq.png)](https://chromewebstore.google.com/detail/obhllchiinbaljbgfbfpfkclniahlkjd)

### 2. 개발자용 수동 설치

1.  이 저장소를 `git clone` 하거나, ZIP 파일로 다운로드하여 압축을 해제합니다.
2.  Chrome/Whale 브라우저에서 주소창에 `chrome://extensions` 를 입력하여 확장 프로그램 관리 페이지로 이동합니다.
3.  페이지 우측 상단의 **'개발자 모드'**를 활성화합니다.
4.  페이지 좌측에 나타난 **'압축 해제된 확장프로그램을 로드합니다.'** 버튼을 클릭합니다.
5.  1단계에서 압축을 해제한 `CaseNoteSearch` 폴더를 선택하면 설치가 완료됩니다.

## 🔧 사용 방법

1.  **자동 하이라이트 사용 (기본)**: 웹페이지에 있는 판례 번호나 법률 조문 텍스트에 자동으로 배경 하이라이트가 적용됩니다. 이 텍스트를 클릭하면 바로 검색이 실행됩니다.
2.  **우클릭 메뉴 사용**: 법률 이름이 없는 조문(`제10조`) 등 자동 인식이 어려운 텍스트는, 드래그하여 선택한 후 마우스 오른쪽 버튼을 클릭하여 원하는 법률 메뉴를 선택해 검색합니다.
3.  **팝업 메뉴 사용**:
    * 브라우저 툴바의 확장 프로그램 아이콘을 클릭하여 팝업을 엽니다.
    * **[설정]** 메뉴에서 '자동 하이라이트' 기능을 켜거나 끌 수 있습니다.
    * **[관리]** 버튼을 눌러 우클릭 메뉴에 표시할 법률을 설정하거나 즐겨찾기에 추가할 수 있습니다.
    * '최근 조회 기록'을 확인하거나 전체 삭제할 수 있습니다.
